MarketScope Calculation Methodology & Heuristics

1. Directional Composite Score (0 to 100)

The score synthesizes trend separation, short-term momentum, volume-weighted anchor, and oscillation:

trend_contribution     = 35 * clamp( 100 * (Fast_EMA / Slow_EMA - 1) / 0.4 )
momentum_contribution  = 30 * clamp( 5_Bar_Momentum_% / 1.2 )
vwap_contribution      = 20 * clamp( 100 * (Close / VWAP - 1) / 0.8 )
rsi_contribution       = 15 * clamp( (RSI_14 - 50) / 30 )

weighted_sum = trend_contribution + momentum_contribution + vwap_contribution + rsi_contribution
Score = round( 50 + weighted_sum / 2 )
  • BUY / Bullish: Score ≥ 65
  • SELL / Bearish: Score ≤ 35
  • NEUTRAL: 35 < Score < 65

2. Rolling-Window RSI(14)

gains  = sum(max(change, 0)) for last 14 bar changes
losses = sum(max(-change, 0)) for last 14 bar changes
RSI = 100 - (100 / (1 + gains / losses))

3. Volume-Weighted Average Price (VWAP)

Calculated from 09:15 IST session open: VWAP = ∑(Typical_Price × Volume) / ∑(Volume) where Typical Price = (High + Low + Close) / 3.

4. Order-Block Zone Heuristic

A closed candle breakout beyond the highest high or lowest low of the prior 5 bars anchors an order-block zone on the range of the preceding opposing candle. A bullish zone is invalidated if a later candle closes below its low; a bearish zone is invalidated if a later candle closes above its high.
