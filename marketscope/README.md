# Zien Quant (MarketScope Core Engine)

Core Python backend, quantitative calculation engine, session manager, and terminal interface assets.

- HTTP Server: `server.py`
- Technical Indicators & Formulas: `market.py`
- Algorithmic Decision Engine: `decision_engine.py`
- Intraday Flow & Funnel: `flow_engine.py`
- Yahoo Finance Scraper: `scraper.py`
- Security & SQLite Database: `security.py`
- Session Management & Archive: `session_manager.py`, `candle_archive.py`
- CLI Management: `manage.py`
- Frontend Assets: `static/`
- Automated Tests: `tests/`
